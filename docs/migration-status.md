# Estado de OpsLaundry (2026-09-12)

El sitio independiente está publicado en `opslaundry.com`, con 40 páginas
físicas en español, inglés, italiano y griego, y las rutas privadas de catálogo
y revisión. El backend propio está en Firebase `opslaundry-2907b`.

La sección de maquinaria de ocasión dispone de **37 anuncios públicos**, seis
contadores y **180 imágenes asociadas**. El build genera **148 fichas** en los
cuatro idiomas. El traslado se limitó a los anuncios ofrecidos en esa sección;
ningún inventario de equipos/NFC forma parte de OpsLaundry.

El catálogo público de recambios v7, las seis Functions, las reglas y los
índices están desplegados. Las plantillas transaccionales de este repositorio
incluyen ambos logotipos; los remitentes y destinos operativos actuales se
documentan en `email.md`.

Quedan comprobaciones reales de entrega de formularios y acceso de
administración con una sesión del propietario. App Check está configurado pero
sin enforcement hasta observar el cliente publicado y resolver el acceso del
build a Firestore. El propietario pospuso estas pruebas; las verificaciones
locales de código y build no las sustituyen.
