# Project Overview

OpsLaundry is the independent home for industrial-laundry services previously
served below `unatomo.com/laundryservices`.

The product covers technical assistance, plant audits, investment review,
automation, used machinery, machine submissions and spare-parts requests. Its
public content is localized in Spanish, English, Italian and Greek.

The first migration phase preserves behavior and visual structure. Brand,
backend and operational evolution can proceed independently after parity is
verified.
